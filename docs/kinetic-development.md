# K-TIC-SYNTH development sequence

1. Repeat copy blend modes and FREE/SYNC feedback refresh using shared BPM.
2. Video chain editor in the bottom-left patch bay: order modules, remove/reinsert modules, rebuild the same video cables used by sockets. Preserve advanced cyclic socket routing; make conversion to a linear chain explicit. Undo and preset import/export cover both methods.
3. Multiline typography, line spacing, alignment and native font kerning.
4. Combined sampling/vertex panel with independent switches and existing routing, plus horizontal/vertical sampling thickness.
5. Second independent typography source, then imported background image with fit, position, opacity and blend mode. Expand to multiple layers after this first stage.

Keep existing preset appearance by default. Preview and test each stage before merging.
