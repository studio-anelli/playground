# Music That Travels · REC-12

Two independent HTML experiences served through a namespaced Next/Vinext route.

- `/experiments/music-that-travels`: entry screen
- `/experiments/music-that-travels/geography`: 100 editions / 102 collection entries, artist and scene associations compared with release markets
- `/experiments/music-that-travels/chromatic`: original 100-record artwork colour trial
- `/experiments/music-that-travels/dataset`: coverage and criteria

The saved full collection contains 610 entries / 608 editions. These experiments use their explicitly labelled study subsets. No collection refresh or colour recalculation runs when opening a study. Copy-specific information remains out of scope.

Sources and provenance are in `source/` and DATASET.md. `worker.js` is generated by `python3 lib/music-that-travels/build.py`; run it after changing source. The route adapter scopes HTML URLs and APIs to the REC. Image proxy caches are namespaced separately from Playground routes. Discogs artwork is fetched on demand and may be unavailable upstream.

Validation: `node lib/music-that-travels/tests/integration.mjs`, plus dataset/layout tests in `tests/`.
